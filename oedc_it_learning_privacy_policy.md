## 1. Overview & Core Privacy Principles

**OEDC IT Learning** ("we," "our," or "us"), package name **`org.oedc.oedc_it_learning`**, is committed to providing an offline-first, privacy-respecting, and mathematically rigorous educational experience.

* **No Account Registration or Sign-In Required:**  
  You are never required to register an account, log in, or provide personal identifiers (such as your full name, email address, physical address, phone number, or social media handles) to use any feature of this application.
* **100% Offline-First Learning Architecture:**  
  All 14 subject families, curated technical domains, interactive code simulations, offline diagnostic tools, and final summative examinations function completely offline with zero external network dependencies.
* **Strict Local Storage Isolation:**  
  All learner data (lesson progress, checkpoint scores, practice code drafts, notes, and cryptographic completion hashes) is stored exclusively in the private sandboxed storage of your physical device using atomic file writes and local preference storage.
* **Zero User Tracking & Telemetry:**  
  The application does not include third-party tracking SDKs, analytics suites, session recording tools, or server-side telemetry. We do not sell, rent, monetize, or broker personal learner data to third parties.

## 4. Device Permissions Declared vs. Unrequested

The application adheres strictly to the principle of least privilege. The only permissions declared in the Android manifest are:

1. **`android.permission.INTERNET`:**  
   Required exclusively to query the Google Play Store for app discovery, display AdMob advertisements, and open external browser links to official reference sources when requested by the learner.
2. **`android.permission.ACCESS_NETWORK_STATE`:**  
   Required to detect network availability so the application can smoothly switch to zero-ad offline mode when disconnected.
3. **`com.google.android.gms.permission.AD_ID`:**  
   Standard permission declared by Google Mobile Ads SDK for advertising identifier functionality on Android 13+.

**PERMISSIONS NOT REQUESTED:**  
The application does **NOT** request, access, or utilize:
* Device camera or microphone
* Precise GPS or background location
* Contacts, call logs, SMS, or calendar
* Photos, media gallery, or shared external storage
* Biometric data or device sensors

## 8. User Data Control, Portability & Deletion

Because all learning metrics, exam records, and progress states are stored locally on your device:
* **Full Data Ownership & Portability:**  
  Learners can export their complete learning history as an encrypted or standard JSON backup and restore it on any device via **Settings > Data & Progress Management > Export / Import Progress**.
* **Instant In-App Progress Reset:**  
  Learners can completely wipe all locally saved course progress, test scores, and streak data at any time via **Settings > Reset All Progress**.
* **Permanent Data Eradication:**  
  You can permanently delete all local data, cached curriculum, and preferences at any time by clearing the application storage via:  
  **Android Settings > Apps > OEDC IT Learning > Storage > Clear Data / Clear Storage**, or simply by uninstalling the application from your device.
